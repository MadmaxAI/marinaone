🌤️ Integração — Previsão do Tempo
A API de clima é usada pelos tenants para exibir a previsão do tempo na marina. A chave é armazenada com segurança no servidor e nunca exposta ao navegador.
Como obter a chave:
• OpenWeatherMap: openweathermap.org/api → plano gratuito permite 1.000 chamadas/dia
• WeatherAPI.com: weatherapi.com → plano gratuito permite 1.000.000 chamadas/mês
• Endpoint de uso nos tenants: GET /api/weather?lat=X&lon=Y
